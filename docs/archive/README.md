# MoonTide 历史文档

> **性质：** Historical archive
> **状态：** 仅供追溯，不参与当前 Rust 契约、产品执行优先级或实现验收。

## 目录

| 目录 | 内容 |
|---|---|
| [`product/`](product/) | 历史产品计划和方向版本 |
| [`guides/`](guides/) | TypeScript 时代工程手册和工作流 |
| [`notes/`](notes/) | 历史架构讨论、迁移计划、评测计划和 backlog |
| [`spec/`](spec/) | TypeScript 时代系统规格和协议草案 |

## 阅读规则

- 当前 runtime 约束以根 [`AGENTS.md`](../../AGENTS.md) 为准。
- 当前 Rust 系统设计以 [`crates/docs/`](../../crates/docs/) 和源码模块 README/DESIGN 为准。
- 当前执行路线以根 [`TODO.md`](../../TODO.md) 为准。
- archive 内部可以保留指向已删除 TypeScript 文件的历史链接；这些链接不属于当前文档链接门禁。
- 历史文档中的“定稿”“完成”“当前”等词只描述当时状态，不覆盖当前实现。
